Acta · Design system

The parts this site is built from.

Every token, type step and component state used across the portfolio and the blog. Poppins for names and titles, Roboto for everything you scan, JetBrains Mono for anything countable. Monochrome throughout: no hue carries meaning, so hierarchy comes from weight, size and a single background step. Dark is the default; every token has a light counterpart and the rail switches between them.

06 · Components

10 primitives · 4 groups

Each primitive is a .jsx with a sibling .d.ts props contract and a .prompt.md with usage. Read the prompt files first; they carry the rules that matter. 09 · The absolutes

Override any default

01  No em dashes in copy, under any condition. Use a comma, a period, a colon, or "and".

02  No serifed fonts. Poppins for titles, Roboto for body and UI, JetBrains Mono for code and metadata.

03  Code is always JetBrains Mono 600 with ligatures, always Dracula, always a dark card with window chrome, and it never adopts the page theme.
